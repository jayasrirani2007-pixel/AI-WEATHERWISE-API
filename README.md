# AI WeatherWise API

## Project Description

AI WeatherWise API is a weather-based application that provides weather information using an API. It is designed to provide users with useful and easy-to-understand weather details.

## Objective

The main objective of this project is to develop a weather API application that can fetch and provide weather information efficiently.

## Features

- Fetch weather information
- Search weather based on location
- API-based weather data
- Backend API integration
- Database integration
- Easy-to-use project structure

## Technologies Used

- Node.js
- Express.js
- MongoDB
- REST API
- JavaScript
- HTML
- CSS

## Installation

1. Clone the repository:

git clone https://github.com/jayashrirani2007-pixel/AI-WEATHERWISE-API

2. Open the project folder:

cd AI-WEATHERWISE-API

3. Install the required dependencies:

npm install

4. Create a `.env` file and add the required environment variables.

5. Start the server:

npm start

## Environment Variables

For security reasons, API keys, database credentials, and other sensitive information are stored in the `.env` file and are not uploaded to GitHub.
